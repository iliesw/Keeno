New package: `bun create keeno` (or `npm create keeno@latest`) scaffolds a Keeno project with Vite, TypeScript and `keeno-check`. Templates: `router` (file-based routing with a layout and a 404 page) and `minimal` (one `App.kn`), with optional Tailwind CSS. Flags: `--template`, `--tailwind`, `--install`, `--force`, `--yes`.
